### What I build

- **Core banking & FinTech backends** — ledgers, KYC/AML, settlement and reconciliation
- **Payment integrations** — banking partners and PSPs, idempotent webhooks, payment state machines
- **Custody & key management** — HSM-backed signing, key hierarchies, M-of-N approvals
- **Blockchain & DeFi** — multi-chain wallets, indexers, swaps, bridges, DEX integrations, staking
- **Smart contracts** — Solidity on EVM, Rust / Anchor on Solana
- **High-load & real-time systems** — event-driven services, load testing, streaming
